# Synthetic examples

- [Volunteer intake application](sample-project/README.md): a completed intake
  slice with an owner decision, delegated default, separate proposal, and explicit
  optional reminder deferral.
- [Community workshop plan](community-workshop/README.md): a scheduling slice
  where discovery was declined. Focused planning continues without a map.

These checked-in examples use explicitly labeled fixture pins for offline testing,
not live releases. Pass `--allow-fixture` to validate or export them. For a usable
resume demonstration, download the real pinned sample continuation ZIP from the
v0.1.0 release. No original private project files are used.
