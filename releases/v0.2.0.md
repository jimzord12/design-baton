# Design Baton v0.2.0

Adds a brief skill-improvement review before slice closure. Discuss observed
friction and worthwhile enhancements, check related issues, and show the complete
public-safe issue draft before filing. Only approval of that issue authorizes
creation. Pending or declined feedback and GitHub failures do not block an
otherwise complete slice. Filing does not authorize implementing the proposal.

## Compatibility

Workspace and map format remains 0.1.0. No data migration is needed. This release
adds a procedural closure requirement, so it uses a minor bundle bump. Existing
v0.1.0 projects retain their current pin; upgrades are explicit. Optional retained
feedback uses context/skill-feedback.md, without changing the machine schema.
